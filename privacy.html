Privacy Policy

Last updated: September 2026
This application is a personal automation tool operated by a single individual developer for use with their own TikTok account only. It does not collect, process, or store personal data belonging to any third party.

1. Data this application accesses

Through TikTok's official OAuth authorization flow, the application accesses only the data required to upload video content to the developer's own authorized TikTok account, such as:

DataPurpose
OAuth access & refresh tokensAuthenticate API requests to the developer's own account
Video file contentUploaded to the account as a post or draft
Post metadata (title, caption)Attached to the uploaded video

2. Data storage

OAuth tokens are stored locally on the developer's own device, in a configuration file that is never transmitted to any third party or external server. No data collected through this application is sold, shared, or made available to anyone else.

3. Third-party accounts

This application does not access, request, or store data belonging to any TikTok account other than the single account explicitly authorized by its developer.

4. Data retention and deletion

OAuth tokens remain stored locally until the developer revokes access (through TikTok's account settings) or manually deletes them. No copies are retained elsewhere.

5. Changes to this policy

This policy may be updated to reflect changes in how the application operates. The "last updated" date above reflects the most recent revision.

6. Contact

Questions about this policy can be directed to the developer through the contact information on file with TikTok for Developers.
